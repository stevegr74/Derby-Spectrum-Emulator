# Spectrum ROM Images

The bundled ROM images are used only to emulate the corresponding Sinclair and
Amstrad machines. Amstrad have kindly given permission for redistribution of
their copyrighted material but retain that copyright.

Included production images:

- `48.rom`: original Sinclair ZX Spectrum 16K/48K ROM
- `128-0.rom` and `128-1.rom`: original Sinclair ZX Spectrum 128K ROM pair
- `plus2-0.rom` and `plus2-1.rom`: original grey ZX Spectrum +2 ROM pair

The additional images were obtained from Debian's
`spectrum-roms_20081224-5_all.deb` package and are retained unmodified. The
package SHA-256 is
`8D25DD300A0C86B4459E152DE3BC657DCA894B167E6A6419EB195D9669BFE950`.
They must not be sold separately or represented as part of DERBY's own
source-code licence.
